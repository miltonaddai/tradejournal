# Trading Journal — frontend

React 19 + Vite + Tailwind CSS v4 single-page app. Install and run it from the repo root; see the [root README](../README.md).

```bash
yarn dev:web                                    # from the root: just this app on :5173
yarn workspace trade-journal-frontend build     # type-check and build to dist/
yarn lint                                       # oxlint
```
